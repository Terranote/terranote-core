## app/services

- `note_builder.py`: Convierte `NoteCandidate` en `NoteDraft` con texto y metadatos.
- `note_publisher.py`: Publica notas en OSM con reintentos y métricas.
- `osm_client.py`: Cliente HTTP asíncrono hacia la API de OSM v0.6.
- `interaction_service.py`: Orquesta sesiones, construcción y publicación en respuesta a interacciones.
